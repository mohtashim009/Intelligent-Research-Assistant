# Dynamic Research Report Structure

## Overview
Updated the research agent to produce dynamic, creative research reports that adapt to the research topic, inspired by academic paper standards.

## Key Changes

### 1. Dynamic Section Structure
**Before:** Fixed structure (Executive Summary → Key Findings → Detailed Analysis → Conclusions → Sources)

**After:** Adaptive structure based on research type:

#### Technical/System Research
```
Abstract
Introduction
Related Work
System Architecture
Implementation
Evaluation
Conclusion
References
```

#### Experimental Research
```
Abstract
Introduction
Background
Methodology
Results
Discussion
Conclusion
References
```

#### Review/Survey Research
```
Abstract
Introduction
Background
Current State
Trends & Developments
Challenges
Future Directions
Conclusion
References
```

#### Theoretical Research
```
Abstract
Introduction
Theoretical Framework
Analysis
Implications
Conclusion
References
```

### 2. Academic Paper Elements

#### Abstract
- 150-250 words
- Summarizes: background, objectives, methods, findings, conclusions
- Appears at the very beginning

#### Introduction
- 2-3 paragraphs
- Background and context
- Importance and relevance
- Research objectives and scope

#### Dynamic Middle Sections
- Adapt to research type
- Examples: Methodology, Implementation, Results, Analysis, etc.
- Each with 2-3 detailed paragraphs
- Proper subsections where needed

#### Conclusion
- Synthesizes findings
- Discusses significance
- Suggests future directions

#### References (not "Sources")
- Proper academic citation format
- Author, Date, Title, Source, URL
- Numbered citations [1], [2], [3]

### 3. Terminology Updates

**Changed:**
- "Sources" → "References" (more academic)
- "Executive Summary" → "Abstract" (standard academic term)
- "Key Findings" → Integrated into relevant sections
- "Detailed Analysis" → Dynamic section names

**PDF Export Updated:**
- Recognizes "References", "Sources", or "Bibliography"
- Special formatting for references section
- Proper spacing and styling
